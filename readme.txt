
en caso de instalar Serenity en una carpeta nueva hacer lo siguente (el mismo caso de ser instalación desde cero )

Introducir este código en la terminal de powerShell con ubicación en la carpeta Shift + click derecho abrir en terminal (no tiene que tener ningún archivo seccionado )

--> python -m venv venv

Creación de un entorno virtual: Todo esto desde la carpeta y abriendo la terminal de VS con ctrl + ñ (esto es para evitar problemas con otras librerías y por si acaso se rompe algo )

--> .venv\Scripts\actívate   <--- esto es cada ves que se quiera correr a serenity

Despues de ejecutar estos comandos Debera salir la dirección de la carpeta donde siguen los comandos de instalación
